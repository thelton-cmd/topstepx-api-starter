# Pine Script to Python

Bring a TradingView Pine Script indicator into the dashboard. The converter turns the script into a
Python indicator that shows up in the chart's **Indicators** menu, with the script's inputs as
settings. It converts your own script into lines on a chart; it does not add rules, levels or signals,
and nothing it draws is a recommendation.

## In the browser

1. Open the dashboard and press **Pine Script** in the header.
2. Paste your script, or pick an example (SMA cross, Bollinger Bands, RSI, Supertrend, a custom function
   with a tuple return, MACD).
3. Press **Convert**. The Python code appears on the right. Notes list anything that was left out or
   approximated. A syntax error names the line and column and selects that line.
4. Type a name (lowercase letters, digits and `_`, starting with a letter) and press **Save as
   indicator**. A message confirms it; open the chart's Indicators menu to add it.

**Copy code** puts the generated Python on the clipboard. The file lands in
`dashboard/indicators_ext/<name>.py`. The dashboard never overwrites a file there unless this converter
wrote it (its first line says `# generated by tools.pine2py ... do not edit by hand`), and it runs the
converted code on made-up candles before saving, so a script that cannot load or compute is not saved.

## On the command line

    .venv\Scripts\python.exe -m tools.pine2py my_script.pine -o dashboard\indicators_ext\my_script.py

(`.venv/bin/python` on macOS and Linux.) Add `--print` to see the code, `--name x` to choose the name.
Details, the supported list and the layout are in `tools/pine2py/README.md`.

## What converts, what does not

Converts: inputs, variables (`var`, `:=`), `if`/`for`/`while`/`switch`, your own functions (including
tuple returns), history like `close[1]`, the common `ta.*`, `math.*`, `color.*` calls, and `plot`,
`plotshape`, `plotchar`, `plotarrow`, `hline`, `alertcondition`.

Does not convert (you get a warning or an error that names the line): strategy orders (entries, exits,
sizing and risk settings; only the conditions are drawn as markers), `fill`, `bgcolor`, `barcolor`,
drawing objects such as labels and lines, arrays, `request.security`, libraries and user-defined types.

## Things worth knowing

- Results are approximations of TradingView's: the dashboard has its own candles, time zone (UTC) and
  no symbol settings. `syminfo.mintick` becomes a "Tick size" setting.
- Each `ta.*` call and each function call keeps its own history, like Pine.
- The routes are `POST /api/pine/convert`, `POST /api/pine/save` and `GET /api/pine/examples`; the first
  two need the page's token. None of them can send an order.
